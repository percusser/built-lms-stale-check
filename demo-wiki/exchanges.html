Exchanges

Owner: Retail Operations · Last updated September 15, 2026

Where customers can exchange

Customers can exchange an item in any store or by mail. For mail exchanges, email the customer a prepaid return label from the order page.

Exchange window

Exchanges follow the same window as refunds. Check the refund policy for the current number of days.

Price differences

If the new item costs more, the customer pays the difference. If it costs less, refund the difference to the original payment method.

One exchange per item

Each purchased item can be exchanged once. A second exchange is handled as a return and a new purchase.
