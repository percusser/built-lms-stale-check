# Demo wiki

The support wiki of Larkspur Supply Co., a fictional outdoor retailer. The Returns 101 sample course is built from these pages.

The pages are plain static HTML with no timestamps or generated IDs, so the text only changes when the policy changes.

`variants/` holds the two edits used in the demo:

- `refunds-v2-14-days.html`: Legal shortens the return window from 30 to 14 days. This is the change the extension should catch.
- `refunds-reworded.html`: the same policy in different words. This should never be flagged.
